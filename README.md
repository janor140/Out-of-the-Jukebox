# Out of the Jukebox
This project tackles "The Earth Information Jukebox" from NASA's Space Apps Challenge 2026. It provides an algorithm that converts any image in 8K resolution into a 30 second audio clip. This involves creatively transforming color spectra, brightness, and pixel density into a melody of self recorded guitar chords, allowing blind people to appreciate the beauty of our planet.

# Details
This project deals with the implementation of a python algorithm that converts any 8K image into a 30 second audio file. The image is divided into 60 slices. Since many NASA images contain large amounts of black from space and dark blue from the oceans, dark colors often dominate the image. To highlight brighter and more colorful hues, only colors above a certain brightness level are taken into account. Each slice is analyzed for color spectrum, brightness, and density. Brightness and density are divided by the maximum value (normalized) to ensure that the result does not sound monotone. These metrics are then converted into chords, volume, and rhythm. Using self recorded guitar chords in FL Studio, this is turned into a short melody that can help blind people connect with scientific footage on an emotional level.

# Use of AI
AI was used exclusively for clarifying challenge objectives and troubleshooting errors. No code or audio was generated by AI.

## Requirements
If you want to try out the code yourself, make sure you have Python 3.14, NumPy, OpenCV, and SciPy installed.
Then run **python jukebox.py**.
